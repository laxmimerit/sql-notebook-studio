## Connections

- **MySQL / MariaDB, PostgreSQL, SQL Server**: host, port, user, password. Paste a connection string to fill the form.
- **SQLite, DuckDB**: pick a file, or leave it empty for an in-memory database.
- **SSL and SSH tunnels** are under the form's advanced sections.
- Passwords go to VS Code secure storage, never into notebooks.

Tag a connection **Production** to be asked before risky statements.
