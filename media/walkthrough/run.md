## Running cells

| Action | How |
|---|---|
| Run cell | `Ctrl+Enter` |
| Run and go to next | `Shift+Enter` |
| Run all | Toolbar → Run All |
| Stop | The stop button on a running cell |
| Pick the connection | Kernel picker, top right |

In results: click a header to sort, use the funnel to filter, double-click a cell to see the full value, switch to **Chart** to plot.
